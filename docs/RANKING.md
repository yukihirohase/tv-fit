# テレビの売れ筋順（楽天市場／Yahoo!ショッピングのランキング）

テレビ型番一覧の「売れ筋順」（既定の並び順）と、一覧・型番ページの「売れ筋ランキング 〇位（436件中）（11/25時点）」の表示。

## 元データ（`src/lib/tv-ranking.ts`）

認証情報がそろっているものを、次の優先順で使う（`chooseRankingCredentials`）。

1. **楽天市場ランキングAPI**（楽天ウェブサービス）：「TV・オーディオ・カメラ > テレビ」ジャンル（genreId `563843`）。1ページ30件、最大34ページを1.5秒間隔で取得する。
2. **Yahoo!ショッピング 高評価トレンドランキングAPI**：「テレビ」カテゴリ（genre_category_id `49520`）。100件ずつ最大1,000件を、1秒以上あけて取得する。注文した人の数やレビュー評価を組み合わせた順位で、純粋な売上順ではない。

- 2026年11月時点、楽天ウェブサービスの管理画面がメンテナンス中（2026-11-09〜、復旧時期未定）でアプリを登録できないため、Yahoo!で運用している。管理画面が戻ったら楽天のシークレットを登録すれば、次の定期チェックで楽天に切り替わる（元データごとに間隔を数えるので、すぐ取り直す）。
- 価格.com のランキングは、利用規約（第13条：情報の複製・転載等の禁止）に当たるため使わない。
- Yahoo!ショッピングのカテゴリランキングAPI（売上順）は 2021-08-31 に提供終了している。

## 更新

- 販売情報の定期チェック（6時間ごと、`/internal/offer-check`）のたびに、前回の試行から約7日たっていれば取り直す（週1回）。
- 取得に失敗したら前回の順位を残し、エラーだけ記録する。30日より古い順位は表示しない。
- 結果は D1 の `tvfit_tv_ranking`（型番ごとの順位）と `tvfit_ranking_runs`（元データごとの更新状況。`rakuten_tv` / `yahoo_tv`）。状況は https://tv-fit.com/offer-status.json の `ranking`（最後に試行した元データ）で確認できる。
- 型番一覧の説明文は、今の順位の元データ（楽天／Yahoo!）に合わせて切り替わる。

## 順位の付け方

- 商品名に含まれる型番（全角・大文字小文字・英数字の間のハイフン・空白の違いは無視。前後が英数字の場合は別の型番とみなす）で、公開中のテレビと照合する。
- 同じ型番が何度も出たら最上位を使う。複数サイズをまとめた商品は、含まれる各型番に同じ元順位を当てる。
- 照合できた型番を元順位の順に並べ、当サイト掲載機種の中で 1位から振り直す（分母は公開中のテレビの総数）。照合できない型番には順位を出さず、売れ筋順では発売日の新しい順で後ろに並べる。

## 設定（Cloudflare のシークレット、プロダクション）

- Yahoo!：`YAHOO_APP_ID`（販売情報の確認と共用。追加の設定は不要）
- 楽天：`RAKUTEN_APP_ID`（アプリID、UUID 形式）と `RAKUTEN_ACCESS_KEY`（アクセスキー）。楽天ウェブサービスの管理画面で、アプリの「許可されたWebサイト」に `tv-fit.com` を登録する（サーバーからの呼び出しにも Referer / Origin が必要）。
- フッターに「Web Services by Yahoo! JAPAN」と「Supported by Rakuten Developers」のクレジットを出している。
