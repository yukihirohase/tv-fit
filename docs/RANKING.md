# テレビの売れ筋順（楽天市場ランキング）

テレビ型番一覧の「売れ筋順」（既定の並び順）と、一覧・型番ページの「売れ筋ランキング 〇位（436件中）（11/25時点）」の表示。

## 元データ

- 楽天市場ランキングAPI（楽天ウェブサービス、`src/lib/tv-ranking.ts`）の「TV・オーディオ・カメラ > テレビ」ジャンル（genreId `563843`）。1ページ30件、最大34ページを1.5秒間隔で取得する。
- 価格.com のランキングは、利用規約（第13条：情報の複製・転載等の禁止）に当たるため使わない。

## 更新

- 販売情報の定期チェック（6時間ごと、`/internal/offer-check`）のたびに、前回の試行から約7日たっていれば取り直す（週1回）。
- 取得に失敗したら前回の順位を残し、エラーだけ記録する。30日より古い順位は表示しない。
- 結果は D1 の `tvfit_tv_ranking`（型番ごとの順位）と `tvfit_ranking_runs`（更新状況）。状況は https://tv-fit.com/offer-status.json の `ranking` で確認できる。

## 順位の付け方

- 商品名に含まれる型番（全角・大文字小文字・英数字の間のハイフン・空白の違いは無視。前後が英数字の場合は別の型番とみなす）で、公開中のテレビと照合する。
- 同じ型番が何度も出たら最上位を使う。複数サイズをまとめた商品は、含まれる各型番に同じ元順位を当てる。
- 照合できた型番を元順位の順に並べ、当サイト掲載機種の中で 1位から振り直す（分母は公開中のテレビの総数）。照合できない型番には順位を出さず、売れ筋順では発売日の新しい順で後ろに並べる。

## 設定（Cloudflare のシークレット、プロダクション）

- `RAKUTEN_APP_ID`：楽天ウェブサービスのアプリID（UUID 形式）
- `RAKUTEN_ACCESS_KEY`：同じアプリのアクセスキー
- 楽天ウェブサービスの管理画面で、アプリの「許可されたWebサイト」に `tv-fit.com` を登録する（サーバーからの呼び出しにも Referer / Origin が必要）。
- 楽天のデータを表示するため、フッターに「Supported by Rakuten Developers」のクレジットを出している。
